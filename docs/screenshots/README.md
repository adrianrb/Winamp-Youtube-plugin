# Capturas de tela

Capturas feitas no Winamp 5.666 (32 bits), com a skin clássica ativada
temporariamente. A skin moderna original foi restaurada depois.

URL usada nos exemplos:

```
https://www.youtube.com/watch?v=nhP8dX5wFtE&list=RDnhP8dX5wFtE&start_radio=1
```

Como essa URL contém `list=RD...` mas não é uma URL `/playlist`, o plugin a
trata como **um único vídeo** (`--no-playlist`), conforme documentado no README.
A playlist do Winamp fica com um item, exibido como `audio` porque esse é o nome
do arquivo em cache (`audio.m4a`).
